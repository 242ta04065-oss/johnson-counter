# 4-Bit Johnson Counter Using Verilog HDL

## Description

This project implements a 4-bit Johnson Counter using Verilog HDL. A Johnson counter is a modified ring counter that uses the inverted output of the last flip-flop as feedback to the input of the first flip-flop.

A 4-bit Johnson counter generates 8 unique states (2n states), making it useful for sequence generation and timing applications.

## Features

- 4-bit Johnson counter design
- Shift register based implementation
- Complemented feedback logic
- Clock-driven operation
- Reset functionality
- Synthesizable Verilog code
